## **🎯 CORE CONCEPT**

Keep the **original full skill/ability/eidolon/constellation/resonance chain text** exactly as it is.
**Only** mark the values or words that changed using inline strikethrough → new value.
Add a **[TAG]** at the start of each changed line.
Do **not** rewrite the description. Do **not** add extra bullet-point explanations unless flagged as **"this explanation"** by the user.
Unaffected text stays **completely untouched.**
Use `[...]` to skip long unchanged sections of text.
When a thing is changed like this for example: **[NERF]** RES PEN type narrowed from ~~**All-Type RES PEN**~~ → **Quantum RES PEN**. *(Value remains **15%**.)* It should not be tagged as a [NERF], do [CHANGED] instead.

## **🏷️ SECTION 1 — CHANGE TAGS**

Always **bold + brackets:**

**[BUFF]** — Increase in power / value
**[NERF]** — Decrease in power / value
**[ADJUSTMENT]** — Neutral mechanical / classification change
**[CHANGED]** — Terminology / reference / type swap with no power direction (e.g., reaction renamed, RES PEN type narrowed at same value, skill name renamed)
**[REWORK]** — Full mechanic overhaul
**[NEW]** — Brand new effect added
**[NEW — Name]** — New named effect added
**[REWORK — Name]** — Named mechanic rework
**[TEXT FIX]** — Wording/tooltip only — no functional change

## **⚖️ SECTION 1B — TAG DIRECTION REASONING (MANDATORY — ALL GAMES)**

**A raw number going DOWN is NOT automatically a [NERF], and a number going UP is NOT automatically a [BUFF]. Always reason through how the character actually plays BEFORE assigning a directional tag.**

### **The Process — in order:**

1. **THINK FIRST** — reason through the character's kit, rotation, resource loops, and what the value actually does in play
2. **SEARCH/SCRAPE to verify** — cross-reference wikis, guides, community analysis (Reddit, YouTube, review sites) for how the change is actually received
3. **TAG + EXPLAIN** — assign the correct directional tag and always attach a short explanation of WHY
4. **UNSURE? REMOVE THE TAG** — if the direction is genuinely unclear after reasoning and searching, output the diff line with NO directional tag at all. Never guess a direction.

### **Common "reduced = BUFF" cases:**

| Change | Actual Direction | Why |
|---|---|---|
| Max Energy / Ultimate cost reduced | **[BUFF]** | Ultimate available more often — faster rotations |
| Cooldown reduced | **[BUFF]** | More frequent usage |
| Energy/Adrenaline/resource cost reduced or removed | **[BUFF]** | Cheaper to use |
| Stack requirement to trigger effect reduced | **[BUFF]** | Easier trigger |
| HP threshold for defensive trigger raised | **[BUFF]** | Triggers earlier / more safely |
| Charge time / attack time reduced | **[BUFF]** | Faster execution |

### **Correct Example (with reasoning + explanation):**

```
*   **[BUFF]** Max Energy reduced from ~~**140**~~ → **130**. *(Lower Ultimate cost — his Ultimate comes back online in fewer actions, making rotations smoother. Since his Ultimate grants a 25% SPD self-buff and his kit converts surplus SPD into Elation, more frequent Ultimates directly feed his damage scaling.)*
```

❌ **WRONG:** `**[NERF]** Max Energy reduced from ~~**140**~~ → **130**.` — this reads the number direction only, not the gameplay direction.

### **Unsure Example (tag removed):**

```
*   Max Energy reduced from ~~**140**~~ → **130**.
```

No tag, plain diff line. This is always preferred over guessing a wrong direction.

## **📝 SECTION 2 — NAME & REFERENCE FORMATTING**

No backticks for skill/mechanic/ability names.

**Bold References — headers, labels, emphasized in-text names:**
```
**[Wind Energy]**
**[EX Special Attack: Moto Slam]**
**[Trial by Cold]**
**[Certified Banger]**
```

**Non-Bold References — general in-text mentions:**
```
[Wind Energy]
[Erosion Mark]
[Trial by Cold]
[Certified Banger]
```

**Parentheses References — short passive/skill references, GI style, descriptors:**
```
(Power Suppression)
(Guidance of Theosis)
(Pathfinder's Blessing)
```

**When to Use What:**

Skill/mechanic name as a section **header label** → **Bold**
Example: **Basic Attack** **[Knight Arts]:**

Skill/mechanic name **emphasized in a change line** → **Bold**
Example: **[BUFF]** [EX Special Attack: Moto Slam] loses its Adrenaline cost — **[Moto Slam]** now activates on Energy alone.

Skill/mechanic name as a **general in-text mention** → Non-bold
Example: Upon damaging a target, Erosion Field inflicts [Erosion Mark] on the target, lasting **6s**.

**GI passive/skill short reference** in-text → Parentheses
Example: (Guidance of Theosis) Elemental RES shred increased.

**GI constellation full title** → Parentheses bold
Example: **C2** **("I Will Guide You and Show You the Path"):**

**Character variant / game system label** → Parentheses plain
Example: Trailblazer (Elation), Mindscape Cinema (Constellations)

**CN + EN name pair** — only include CN when needed for correction, translation, or text fix. Otherwise omit CN:
Example with CN needed: **[Blade Spiral / 旋刃]**
Example without CN: **[Blade Spiral]**

## **📢 SECTION 3 — INLINE DIFF FORMAT**

**Numbers / Values Changed:**
```
*   **[BUFF]** DMG Multiplier increased from ~~**220%**~~ → **240%** of ATK.
*   **[NERF]** CRIT Rate conversion reduced from ~~**25%**~~ → **20%**.
*   **[BUFF]** Flat ATK bonus increased from ~~**240**~~ → **300**.
*   **[BUFF]** Max Energy reduced from ~~**140**~~ → **130**. *(Lower Ultimate cost — faster rotations; see Section 1B)*
*   **[NERF]** Cooldown increased from ~~**16s**~~ → **17s**.
*   **[BUFF]** Toughness DMG (Single Target) increased from ~~**5**~~ → **10**.
```

**Unsure direction — no tag (Section 1B):**
```
*   Max Energy reduced from ~~**140**~~ → **130**.
```

**Words / Text Changed:**
```
*   **[TEXT FIX]** Wording updated from ~~"a random enemy"~~ → **"one random enemy"**.
*   **[ADJUSTMENT]** Trigger rate now based on ~~[Hidden Punchline]~~ → **[Hidden MMR]**.
*   **[CHANGED]** Terminology updated from ~~"Stellar-Conduct and Stellar Swirl"~~ → **"Stellar Glimmer"** (星烁).
*   **[CHANGED]** Name updated from ~~**[Twittering Quartet]**~~ → **[Chirrup Quartet]**.
```

**New Effect Added:**
```
*   **[NEW]** During Enhanced Basic ATK, DMG taken by enemy targets in the Zone increases by **20%**.
*   **[NEW — Entropy Shift Passive]:** While in Entropy Shift states, Denia gains **+60% ATK** and **+60% Fusion DMG Bonus**.
```

**[NEW] Referencing a Game Mechanic Keyword — ALWAYS include the original definition (ALL GAMES):**
When a **[NEW]** line references a named game mechanic/keyword (Follow-Up ATK, Sheer Force, Coordinated Attack, etc.), always add the mechanic's **original in-game definition text** as an indented sub-bullet in bold parentheses:
```
*   **[NEW]** In solo-Elation teams, when Aventurine • Waveflair deals DMG using his Elation Skill, it is considered as launching a Follow-Up ATK.
    *   **(Follow-Up ATK)** Unleashes an extra attack on the target. This effect is triggered automatically when requirements are met.
```
The definition comes from the game's own data/terminology — search/scrape if not present in the provided data.

**Rework Block (Old → New):**
```
*   **[REWORK — Effect Name]:** *Old Effect:* ~~Ultimate additionally increases the SPD of one designated ally by **12%** for 3 turns.~~
*   **[REWORK — Effect Name]:** *New Effect:* When using an Elation Skill, increases this unit's **CRIT DMG by 100%** for 3 turns.
```

**Reclassification / Structural Change:**
```
*   **[ADJUSTMENT]** Reclassified from **Special Attack** → **EX Special Attack**. *(Energy cost of 40 retained)*
*   **[ADJUSTMENT]** Activation condition changed. *Old:* Requires [Trial by Cold]. *New:* Hold input to activate — [Trial by Cold] requirement removed.
```

**Stat Node / Ascension Node Changes — ALWAYS full explanation with total (ALL GAMES):**
When stat nodes change type or value, always explain the change and calculate the **total** across affected nodes:
```
*   **[ADJUSTMENT]** Ascension 3 / 6 stat nodes changed from ~~**DEF 5% / 7.5%**~~ → **Elation 4% / 6%**.
    *   **(Elation Boost)** Total Elation from stat nodes increases by **10%** total (4% + 6%) after the change — replacing **12.5%** total DEF (5% + 7.5%). Shifts stat node value from defense into his core Elation damage scaling.
```
Always show the math: `X% + Y% = Total%`

```
**Base ATK:** 674 | **Substat:** CRIT DMG 36.8%
```

**Stacks / Turns — Always Calculate and Show the Total:**
When a skill description mentions stacks or turns with per-stack or per-turn multipliers, calculate the max total and show it inline.

Example:
```
lasting for 2 turn(s) and stacking up to 3 time(s). Each stack of "Safe Escort" increases Assist Skill DMG by 25%. When "Safe Escort" reaches 3 stacks, each stack of "Safe Escort" increases Ultimate DMG by 30%.
```
→ Add after the relevant line:
*(Assist Skill DMG Total at Max Stacks: 3 × 25% = **75%** | Ult DMG Total at Max Stacks: 3 × 30% = **90%**)*

Always show the math explicitly: `N × X% = Total%`

## **👤 SECTION 8C — CHARACTER MEDIA GALLERY FORMAT (MANDATORY)**

**This format is MANDATORY whenever the data contains character/agent/resonator changes.** The character's **splash art or character reveal image** goes in a media gallery (type 12) placed **directly above that character's text block**.

**END OF COMPACT DIFF FORMATTING GUIDE — FINAL**

> **How to use:** Copy-paste this entire document into a new chat. Drop your raw version diff data immediately after — **no extra prompt needed. JSON Component V2 output will be produced automatically.**
>
> **Links:** Posting a nanoka /diff or gachabase changelog link triggers a full scrape/read of that page plus cross-referencing with wikis and guides for accuracy (Section 4B).
>
> **Tag direction:** [BUFF]/[NERF] tags are assigned by gameplay reasoning + verification, never by raw number direction — with explanations attached. Unsure = tag removed (Section 1B).
>
> **Character data:** The Section 8C character media gallery format is applied automatically — one container per character, splash art / reveal image gallery directly above the character's text. First container carries the patch header; continuation containers start with the image.
>
> **Equipment/item data (weapons, artifacts, light cones, relics, planar ornaments, W-engines, disc drives, bangboo, echo sets, etc.):** The Section 8B interleaved media gallery format is applied automatically — one type 12 gallery per item, directly above its text block. Paste your image URLs into the per-item galleries (or placeholders will be created for you to fill in).
>
> **Flagging explanations:** Mark sections in your raw data with **"this explanation"** and the output will include a proper Highlights / per-character summary paragraph inside the JSON content.
