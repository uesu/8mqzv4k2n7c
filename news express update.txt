Nothing else about the new Reddit engine — structure, ordering, text, delivery, continuation, dedup/record JSON, Devvit relay, Twitter engine, Game-Express — changes.

## 2. Discord facts
| Component (type) | spoiler |
|---|---|
| Media Gallery (12) item | `{"media":{"url":…},"spoiler":true}` → blurred tile with "SPOILER" pill |
| File (13) | `"spoiler": true` |
| Thumbnail (11) | `"spoiler": true` (not used by the Reddit engine; leave alone) |
| Container (17) | `"spoiler": true` blurs the whole card — **do not use** |
Spoilered video loses the fullscreen button → ruling 2.

## 3. Implementation (read `testing area/reddit_main_v3.py` fully around the intake-record parsing and `build_v3_payload` before editing; VERIFY every anchor)
1. **Record → flag.** Where the v1 record becomes the engine's item, derive  
   `blur = bool(rec.get("spoiler")) or bool(rec.get("nsfw")) or bool((rec.get("parent") or {}).get("spoiler")) or bool((rec.get("parent") or {}).get("nsfw"))`.  
   Non-intake / legacy paths without these fields → `blur = False` (unchanged output).
2. **Builder.** Where gallery/media items are assembled, if `blur` set `"spoiler": True` on each **image** item (`i.redd.it`, `preview.redd.it`, `external-preview.redd.it`, any `.jpg/.jpeg/.png/.webp/.gif`). Every **video** item/component — however the builder emits it today (gallery item with `attachment://…mp4`, File component, direct URL, or a mirror link such as embedez/redditez/vxreddit) — gets **no** `spoiler` key. When `blur` is false, do not add the key at all (payload identical).
3. **Multi-part posts** (`bodyTruncated: true`, e.g. the 26 KB HSR 4.7 patch notes): the rule applies to whichever message carries the image items; text parts untouched.
4. **Late flag flips** (v2 update rows): implement **only if** the existing update handler already PATCHes posted cards (for `edited`/`removed`) — then rebuild with the new `blur` and PATCH once within the existing window/counters. If it does not edit cards today, leave it out and note it as a possible follow-up in the ROUND file. Do not build new edit plumbing.
